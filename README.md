# MovAD Benchmark

This repository hosts the official resources of MovAD, a moving-camera video anomaly detection benchmark introduced in our paper:

**MoDec-VAD: Motion-Decoupled Multi-Granularity Learning for Moving-Camera Video Anomaly Detection**

## Dataset Description

MovAD is constructed from publicly available datasets, including DoTA, UiT-ADrone, SeaDronesSee, and ECVA.

Due to copyright restrictions, the original videos are not redistributed in this repository.

This repository will provide:

- Benchmark annotations
- Training/testing splits
- Device-category labels
- Evaluation protocols
- Evaluation scripts

The above resources will be released upon acceptance of the paper.

## Data Availability

The MovAD benchmark is built upon publicly available video datasets. 
We will release the corresponding annotations, data splits, and evaluation protocols after acceptance of the paper.
The original video data remain available through their respective source datasets.
